Suggested click path
  1. Log in as admin → open Score hub / Test analytics → show class heat maps and alternative effectiveness.
  2. Admin → Teaching time → filter by instructor / class.
  3. Log in as instructor → open a class → expand broad categories → student attempts (item detail).
  4. Instructor → activate a quiz or test for whole class or selected students.
  5. Log in as student → open curriculum lessons → take a progress check → take a knowledge test (one question at a time).
  6. On a lesson: Helix dock → allow camera → click 9 marks → read. Then instructor → class → Attention signal (not a score).
  7. Optional: Binary game, tickets on curriculum, instructor inbox.
How to run (Mac)
cd ~/Downloads
unzip -o ciwt-lms.zip
cd comptia-lms
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
PORT=5050 python app.py

Open http://127.0.0.1:5050. For a peer on another network, use a Cloudflare quick tunnel to that port. For production-style runs use gunicorn (see Gaps & ops).
